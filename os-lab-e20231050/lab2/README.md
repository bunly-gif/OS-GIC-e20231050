## Reflection
This lab helped me understand the difference between relative and absolute paths. A relative path depends on the current working directory, while an absolute path identifies a location from the root of the filesystem. I also learned how `mv`, `cp`, and `cat` work with file paths containing spaces, and how to diagnose and correct a path error.
